# 目标与评价 · 核心

版本 `guidance-20261016-v1`；只用于下一合法未冻结边界。各线沿自己的目标、阶段、授权与预算；旧冻结件、失败、暂停和执行入口保持。短版承接原规则，不能解封数据、恢复研究或授予采用权限。

- **先定问题与证据层级。** 在原 PLAN／SPEC 写明本线、问题、阶段、固定父本／对照、窗口和有限预算。数学／信息、工程、账户经济、独立确认分别判定；缺证与故障记未知，不能当经济反证，已花成本与额度不返还。
- **账户目标。** 先核正确性、买前时点、可成交性和完整连续现金账户；同窗口、费用、撮合与容量比较。主策略在原始日终最大回撤≤20%且自身费后盈利后，优先更高费后几何年化，不要求回撤逐次下降，不事后缩放资金。统一展示年化（250日）、原始回撤、Calmar和对照年化差（百分点），利润留作核账；Calmar不能替代收益。
- **先写决定条件，再看结果。** 固定直接父本、已审阅最强风险合格对照及同框架高收益参考，角色可重合。根据费用／容量、数值精度或不确定性证据说明实质增益，并固定一个针对主要脆弱性的对照和拒绝条件。数学正差不自动晋级；依据不足保留原父本，记“观察改善、晋级证据不足”。不新增通用5个百分点或删年全胜门槛；本线明确授权的特定目标仍有效。
- **滚动验证（v2 可选，批次边界冻结 `walkforward_contract` 后生效）。** 新经济候选另跑冻结的滚动验证（可见 2020—2022，2023／2024／2025 各一折），至少 2 折胜过父本、平均差不小于 0、各折回撤不超过 20% 才算开发证据支持；只在全窗口上再次胜出记“观察改善、晋级证据不足”。Agent 只读遮蔽版结论，不打开完整验证数字。这仍是开发证据，不是独立确认。
- **保留独立性。** 默认2020—2025为开发，2026封存，按本线有效授权判断；已用于选择的资料不能重新命名为独立确认。确认前固定候选、强对照、窗口／终点、最低经济效果及风险、支持／不确定性要求；确认和正式采用各沿原权限。核账正确、开发进步、方法提效、独立盈利不能互相替代。

按动作读取：账户评价用 `evaluate --stage economic`，独立确认用 `confirm`；具体费用、公式、失败分类及历史来源由读取器返回相应原文章节。信息／工程阶段不为了统一指标强跑账户。复用有效核验与原记录，不增加逐轮评分表。
