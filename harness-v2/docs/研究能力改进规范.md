2026-10-15，版本 v4；接入标识 `research-capability-20261015-v4`。沿用收益来源、失效诊断、分层评价与经济优先的候选准备，新增证据到 harness 版本、实际任务和效果比较的闭环；[v3 原文](../analysis/research_method_supervision_20260922/harness_loop_20261015/before/docs/研究能力改进规范.md)及 [v1 原文](../analysis/research_governance_20261008/alpha_diagnosis_20261013/before/docs/研究能力改进规范.md)保留供旧冻结件核验。本页统一后续选题、实验设计、反思及方法验证；复用各线原 PLAN／SPEC、候选池、冻结、结果与交接，不增加一套 CURRENT、评分器或逐轮报表。

## 1. 目标、适用范围与生效边界

研究能力指：在可比较的总预算下，更有效地发现值得检验的经济问题、排除重要错误解释，并找到证据更可靠的高收益策略。实验数、模型数、文档数、提示词版本、独立核账通过和循环次数不能单独证明研究能力提高。

- 适用于本项目研究总控及各策略／专题研究线的下一未冻结准备、选题和反思；在途实验与已哈希绑定的 PLAN、SPEC、池文件、ENGINE、质量合同保持原版。需要更新时另立版本，在下一合法边界绑定；必要核验和结果收取继续。
- 各线沿自己的目标、阶段、固定对照、授权及预算；主策略完整账户沿现行风险约束与费后利润目标。高涨幅、炸板、因子／跨股专题不因引用本页继承主策略评分、账户阶段、执行权限或调度 CLI。暂停、归档、已关闭表达及封存范围不由本次维护恢复。
- 既有更具体授权继续有效，包括 ML2 已获得的聚宽研究授权；不得收回或传播给其他线。本页不新增原生、付费、实盘、正式采用、计算名额或封存数据权限，不配置自动化。
- 本页要求实际研究行为接入，不把“文档已读／已发消息”记为已采用或提效。完整成本或独立验证不足不妨碍无依赖的已授权普通研究。

## 2. 每轮从收益来源、失效诊断与竞争解释开始

每个实质策略问题在原 PLAN／SPEC 中承接“收益来源 → 失效诊断 → 修改检验 → 更新认识”。先引用当前策略整体研判，再写本轮要改变的判断；已有字段足以表达时不另建卡文件。alpha 是待检验的可交易收益机制，不能仅凭高回测收益、特征重要性或动听的解释认定已捕捉。机制未知时明确未知及区分检验，不要求先有完整答案才能研究。

| 原字段或记录位置 | 必须回答 |
| --- | --- |
| question / mechanism | 当前策略被认为靠什么赚钱、在什么条件下有效；本轮改的是信息／选股、入场、退出、仓位还是执行，针对哪个收益瓶颈 |
| source_evidence / rationale | 收益机制的直接证据、间接依据、反例与未知；至少一个有依据的竞争解释，以及与旧失败的实质差别 |
| failure / 原诊断 | 在哪些年份、可观测条件或交易中失效，涉及多少机会；沿机会→信号→排序／仓位→下单成交→退出→费后账户定位。区分信号衰减、训练／标签错配、动作未触达、资金／持仓路径、费用／容量与工程故障，尚不能区分就写未知 |
| first_test / data_clock | 修改为什么可能修复该失效或补充收益；哪个最小对照能区分竞争解释，预计改变哪些真实动作；实际输入与决定前可知时点，以及可复用核验 |
| falsifier / stop_rule | 什么结果否定本表达，什么结果使下一步继续、转向、暂存或停止；必要补证的具体终点 |
| budget / 原计划 | 原授权内的研究、生成、实现、执行、核验及沟通成本范围；新增产物量级；未知不补零 |
| 原对照与验收段 | 同口径对照、完整账户判据或本阶段证据等级、后续经济验证路径与当前缺口 |

研判同时参考盈利、亏损及遗漏机会，保留完整母体、支持量与未知；条件若来自事后结果，只作探索诊断。按当前疑点区分信号增量与市场／风格暴露、仓位和复利、少数尾部或反复选优、撮合假设的影响；分组描述、随机对照、消融或风险匹配各有适用范围，不要求每轮全做，也不将描述归因冒充因果证明。

先核来源、时点、可执行性及真正影响当前决定的正确性，再比较经济影响范围、证据强弱、区分解释的能力、成本与依赖。保留有依据的主链外方向；不按任意固定比例分配，不用改名或邻近阈值凑候选。

已有信息价值／成本等级只是有依据的排序等级，不是预计利润或成功概率。没有可信数量依据就写范围、证据级别或未知。不得把想象的收益上限、过度精确的主观分数包装成经济证据。

完整账户阶段在新冻结件中同时标明：同框架高收益参照、已审阅范围内最强风险合格对照、直接父本。角色可重合；缺少可比对象明确未知及最小补证。超风险参照只用于揭示代价，跨框架历史成绩不能直接当合格父本。各线复用已有比较附件，不重建核账链。

出现收益显著牺牲、持续局部父本改善却未缩小重要差距、或连续准备未改变判断时，在原自然反思／已允许的提前反思中重新比较资金使用、动作映射、信息来源等竞争解释。不得默认继续换模型，也不能默认取消风控或扫仓位比例。离线代理指标通常用于排序与诊断；其经济否定须有对应假设和判据，不能代替本应由完整账户回答的问题。来源、泄漏及不可执行性仍可拒绝准入。

## 3. 结果必须更新策略认识与下一选择，但不能扩大判词

每个实质问题结束，在原结果／反思中写明：原收益与失效假设；实际动作及费后结果；哪些解释得到支持、被否定或仍未知；适用／失效范围；下一步因此继续、转向、暂存或停止什么。结论只描述收益涨跌而未更新判断时，补明尚缺哪项区分证据；不为填表硬编原因或追加计算。关闭表达同时保留重入所需的实质新证据，原始失败与未知不覆盖。

实现故障、资料未知、有效经济反证分开。一种表达失败不封死整个机制族；不得通过改名、看结果后换阈值或窗口救回原表达。不能把“某预算严重压低收益”推广为“所有风控无效”。一次检查成功或反思文本不能自证这条经验提高了研究能力。

删除分支后收益下降，只支持该分支在固定账户中的贡献；某过滤器在牛市失效，不证明原市场分类正确。首个交易分叉、相关性或期末权益差，不能直接当作某机制的独立因果收益；更广的归因须有相应对照证据。

每轮更新的是本轮改变的认识；来源准备、工程修复和不变检查引用已有研判，不另算 alpha 实验、不重做全套归因。沿原反思节奏汇总整体策略认识，不新增逐轮报表、审批或计算配额。相同输入、实现和判据已有有效核验时直接复用；新差异再定向补查。

## 4. 策略实验与研究方法实验分开验收

策略实验改变交易表达；方法实验改变问题生成、选题、实验顺序、证据复用或停止／转向方式。策略开发收益上升不直接证明方法更强；普通策略研究不必等待方法比较结论。

方法候选在原 PLAN／试点协议事前写清：要解决的方法缺陷与触发证据、旧方法、一个明确的修改面、适用问题及可见信息、可比较预算、评价维度、停止／回退条件、版本与证据引用。首个最小试点宜只比较选题方法，固定模型与执行工具，避免多处同时变化后作单因素归因。

- 历史回放仅使用当时实际可见信息和已有路径；缺失的未选分支不能用猜测或相似案例补造。已读答案的历史只作开发／诊断。
- 前瞻比较使用尚未参与方法设计、结果尚未揭晓的匹配问题／完整研究族；事前说明分组、依赖、信息隔离与方法差异。只比较选择器时尽量固定候选池；比较候选生成时固定原始信息与生成预算，另立修改面。
- 同预算须覆盖生成、维护、实验、核验和沟通的已测成本；请求数相同不等于成本相同，缺项保持未知。两批先后成绩不同不能自动作因果解释；无法形成公平对照时标为前瞻观察。
- 分别判断：最强合格账户是否改善、重要经济缺口／错误解释是否得到解决、完整成本是否减少。廉价否定不能抵销长期没有更好账户；不另造加权总分，不给无经济证据的结果补质量分。
- 第一批可验证接入可运行，效果需要后续可比较证据；不能凭单次幸运命中宣布普遍提效。试点失败、无优势或证据不足按原协议保留／回退，保留所有尝试。每线只运行原规则允许的方法试点，不叠加或扩预算。
- 验收依据原事实与独立复核，修改者不能同时放宽判据自证成功。检查器有缺陷时单独修复和验证版本；公平性、任务匹配和完整成本证据仍须真实存在。

## 5. 三种证据不得混同

| 证据 | 回答什么 | 不能替代什么 |
| --- | --- | --- |
| 独立核账／实现复核 | 时序、订单、现金、费用、计算是否正确 | 不证明方法提效或样本外盈利 |
| 研究方法的前瞻验证 | 新方法面对后续研究问题是否更有效 | 若仍用反复开发行情，不因此获得策略独立确认 |
| 策略的独立经济确认 | 未参与开发／选型的合法市场证据是否支持盈利与风险结论 | 不自动证明研究方法的因果优势 |

反馈被用于修改方法或策略后，后续用途记为开发，不能重命名为独立保留。研究问题可见时间与交易数据可知时间分别记录。独立确认的窗口、支持量或阈值未定就保持未知；另按原确认协议与权限推进，不解封数据补成绩。

## 6. 实际接入、程序能力与汇报

结构／旧 ML 继续使用原 next → observe → cycle／review-pilot。新卡写入尚未冻结的 PLAN／SPEC，并经原 generation_evidence／source_evidence 单向引用和哈希绑定；不要构造 PLAN 与 SPEC 相互包含对方哈希的循环。其余线用本线已验收入口承载等价内容。

下一未冻结候选池先用原PLAN说明经济瓶颈、竞争解释和为何值得本批预算，缺少决定价值的项暂存；不能为降低派发次数而改family或隐藏其他候选。research_frontier.v1 保留原格式，least_served_family_v1 继续按原机制族／信息价值／成本等级排序。2026-10-15 P1 新增的 bottleneck_evidence_cost_v1 显式读取原 SPEC 的 selection_basis 与 budget.resource_seconds，需在新边界绑定 selection_contract；格式及影子比较见[运行手册第 11 节](研究调度运行手册.md#11-2026-10-15-p1具体选题与方法反馈)。程序核对引用与声明一致性，不能自行证明经济解释或预计成本真实。RRSI v3 的失败预测反馈只改变原行动顺序／深度候选，不扩大执行组件和动作级回放的证据资格。

实际改变选择算法前，须完成有界实现、针对性验收并在新边界冻结，沿原试点授权运行；尚未实现时可准备候选与方法提案，继续原合法研究，不绕过 next、不伪造已按新算法选择。格式检查通过不等于方法语义检查或经济证明。

提示词、候选生成、上下文组织现由 [Harness 反思与改进闭环](Harness反思与改进.md)提供独立可执行入口，不能以 `cycle --rrsi` 的行动回放替代。Agent 用原失败／成功证据提出单组件改动，独立复核后实际执行组装任务；以同模型、同原始输入、同预算和冻结阶段判据比较，保留原成功案例及全部失败／未知。原执行批次的 D/O 与成本通过 `execution_feedback` 回到下一轮反思。未测完整成本不宣称节省；新版本仅在合法未冻结边界绑定，不叠加修改 policy／selector，不替换在途件。各专题线须由本线实际消费者适配，规范存在不算已接入。

在原 PLAN／冻结件／反思保留本页版本引用及本线承接内容；已有充分内容可以直接绑定，不为字段再重复实验。原交接只补一个最短引用，不复制本页。总控沿现有记录跟踪下列层次，不增加汇报频率或定时器：

1. 规范已发布、提示已送达；
2. 下一未冻结计划／候选规格已实际绑定，注明边界与改动；
3. 决策和实验已按计划执行，结果通过相应核验；
4. 方法优势、策略开发进步、独立经济确认分别取得证据。

汇报先回答“经济上改变了什么、距离强对照差多少、下一决定为何改变”，再列成本与必要未知。方法测试、独立核账及规则修订不计作新的独立经济假设。新增产物依[研究产物治理](研究产物治理.md)，只在原回执累计文件数与逻辑字节。
