# 研究总控监测协议

后续研究按[研究能力改进规范](研究能力改进规范.md)核对经济瓶颈、失败学习与方法比较；本协议只规定观察、介入和记录方式。规范发布、计划绑定、执行、方法效果和经济确认分开，暂停／关闭线不因规则发布被唤醒。

总控首先承担[研究负责人的决策与结果接续职责](研究方法督导机制.md)；本协议提供必要观察、风险纠正和介入记录。一次完整巡检不等于完成负责人工作，也不能挤占原预算内已明确的主问题研究。现行所有权与历史接管记录见原 STATE，不在本文维护会话映射副本。MS013、MS015 和 MS028 的历史原件继续保留，不建立新的研究 CURRENT。

监测所有权、对象、游标与当前接续点只写回[原 STATE](../analysis/research_method_supervision_20260922/STATE.json)。[首轮基线](../analysis/research_method_supervision_20260922/controller_handoff_20261006/BASELINE.json)是带来源和时间的观察快照，不是各线运行状态或执行授权；[轻量介入记录](../analysis/research_method_supervision_20260922/INTERVENTIONS.jsonl)与原 `guidance` 互相引用。旧历史、原失败、冻结件与研究权威指针保留。

## 一、范围和目标

- 主策略的新未冻结完整开发账户沿 MS028：2020—2025，同窗、同本金、同费用和撮合的正确完整现金账户，原始日终权益最大回撤（含初始本金峰值）≤20%，约束内优先费后利润。旧冻结合同按原判据；不热改在途实验。
- 实质经济进展依据候选与事前固定对照的完整账户增量、风险、稳定性与成本。仅降低风险但少赚的结果明确记录为收益取舍；准备成功、预测分数、送达或循环次数不算收益改善。各线不同账户不能横向拼成绩。
- 独立样本外未评估或支持不足 = `unknown/null`，不能写“不劣化”。必须另有事前完整确认协议和足够独立证据，才可判断收益改善与风险不劣；开发胜出不等于整体目标完成。
- 2026 个股特征、个股／策略收益及跨年退出继续封存，既往暴露不清零。缺跨年退出保持删失和未知；不能为补完整结果自动解封。原生回测、历史滚动、反复使用的选型窗口均不自动获得独立资格。
- 炸板沿自己的目标、状态、授权和预算，不强套 MS028 分数，不继承 main_strategy 权限。Rust、压缩资料及工程维护只计工程效果。总控不放宽收益、风险、独立确认或执行标准。

`STATE.targets` 是完整观察对象入口，新增研究线登记后即进入必要观察范围；不使用本文中的静态名称清单筛掉新对象。只读取对应权威状态的交付标识、下一动作、承接需求和必要游标，按原有界预算核查新增证据。各线暂停、归档、关闭阶段、封存和更具体禁读依原授权及权威状态保留，不因登记恢复。线程 idle 不表示其研究授权撤销，也不授权总控自动续跑。新增对象先核项目归属与原授权。

ML2 作为独立研究线纳入项目研究判断：沿 [ML2 当前规则](../analysis/yjj_ml2_research_20261007/CURRENT_RULES.md)、OWNER、批次与原结果读取必要本地证据。没有可用聊天接口时将其记录为本地产物观察对象，记录来源与观察时间，不能因不在 `wait_threads` 中漏掉，也不能伪造线程、向 Claude 发未授权指令或改写其执行状态。跨线比较先核父本、窗口与执行口径。

本协议本身不授予训练、回测、经济账户、新并发或额度，也不恢复暂停或自动化。总控判断、消息与配置按现有有效用户授权执行，不能从某次维护记录推导永久停工或新增权限。

## 二、一个心跳，三种到期工作

每次有效唤醒先在原常规5分钟观察预算内核对 STATE.targets 的新增交付及 coordination 的未承接事项，再接续当前主问题。专题已交付、等待策略线接收时，总控必须明确接受并沿原授权去重派发、比较优先级后暂存、或有证据地拒绝；记录承接者、自然边界、实际回执或重新进入条件。登记到 targets、线程 ACTIVE 和重复心跳不能替代承接。主问题优先级不构成忽略已登记交付的理由。没有新增交付或正确性异常时，直接把原授权与预算用于主问题推理和裁决，不展开全线原件审计。用户明确暂停本任务研究时按其范围停止；仅定时配置暂停不被解释为永久取消其他已授权工作，手动维护也不自动恢复定时。

| 到期条件（北京时间） | 有界动作 | 去重和接续 |
| --- | --- | --- |
| 每小时必要观察并接续研究 | 使用 `wait_threads` 的 compact snapshot，传现有 `afterCursor`，一次最多八个目标，常规 `timeoutMs: 0`；仅查新结果／错误／状态变化，ML2 取必要本地产物 | 返回提前结束只补本次未返回目标；不重复查询已取得的快照。游标只是通知去重，不是经济证明 |
| 当日首次 20:00 后 | 明确当前主问题、各线优先级及理由、改变的判断、完整经济进展和最小缺口 | `monitoring.daily.last_completed_date` 去重；无新可行动结论可只落接续点，不强制通知或改 loop |
| 每周首次到达周一 09:00 后的心跳 | 查询截至观察日近 30 天的 RSI/RRSI／研究代理自我改进原始论文及作者代码；比较新增版本、失败条件与可检验的项目适配 | 用北京时间 ISO 周和原始版本去重；已完成周不重复查。离线后只补一次当前周，不补跑历史周 |

小时、日、周工作共用新总控的同一心跳，不能堆定时器。日历只决定何时看，不要求按时换方法。没有变化或可行动证据保持安静；仅重要新证据、完成、重大失败、回退／泄漏或用户必须决定时通知。

先按根 AGENTS.md 读取本协议所需字段，变化后才读新增轮次及精确原件。权威状态每线一次，报告观察时间；不等版本静止，不追查并发写入者，不遍读大表或全库日志。无变化可复用有效核验，缺证据时列出最小缺口，不为了补齐表格重算。

`automation-5` 的当前配置与实际自动唤醒分别核验，读取现有配置及 STATE 原回执，不由本文推断 ACTIVE／PAUSED 或首次运行。首次实际触发须有该自动化真实 turn／运行回执；人工聊天、维护及旧自动化回执不能顶替。未来时刻未核验保持空值。

对用户已要求持续服务的数学线，按[负责人职责](研究方法督导机制.md#持续数学与统计研究能力2026-10-09用户要求)和本线提示词，区分岗位持续状态、当前独立课题、各候选待验证三层。首题交付或等待策略线不能直接推导整线完成；检查本线是否已比较并实际接续另一个有据问题，同时把承接线真实反馈供本线修正方法。此检查并入原5分钟必要观察，不新增全线扫描、汇报表或定时器。用户明确暂停或确无可行动证据时按真实范围记录，不强造研究工作。

## 三、四类证据怎样检查

| 类别 | 最少核对内容 | 结论边界 |
| --- | --- | --- |
| 完整账户收益／风险 | 候选和对照身份、同窗日历／本金／费用／撮合、原独核、订单／持仓／现金／费用闭合；费后利润、增量、原始 MDD、逐年及尾部集中、费用敏感性 | 缺账户或未闭合不评分；工程停点不是经济反证；敏感性未评估保留空值 |
| 独立样本外／暴露 | 训练、选型、滚动检验、独立确认的实际用途；决策可知时点、完整机会池、失败／未知、跨年标签；谁何时见过哪些反馈 | 已用于选型或看反馈后改模型的窗口记为已暴露；旧数据不能换名成为新保留集 |
| 实际研究循环 | 原 PLAN／合同、冻结版本／哈希、真实 next 决策与 observe、每三问实际 cycle 或同输入有效引用、RRSI 原版／失败／回退 | 结构与 ML 按[调度提示词](研究调度提示词.md)及[运行手册](研究调度运行手册.md)；市场／专题按本线入口，不能伪称所有线运行同一调度器 |
| 工程和数据效率 | 故障是否重复、已消耗修复额度、未决身份、来源缺口、准备／执行／核验／等待／维护／沟通总成本 | 完整成本缺失不计零，不宣称节时；工程进步和策略收益分开；未知任务按身份接收而不重提 |

复用[研究验收标准](研究验收标准.md)。只按现有原件能支持的范围判断；摘要、哈希、布尔声明或工具接受不替代原执行／核验。变更结果影响后续决定前，定向复核原合同与证据；未改变的输入、实现和判据复用原有效检查。

独立确认前必须在原计划事前冻结：唯一候选与固定对照、合法且未参与选择的窗口／结束条件、数据暴露清单、费用与执行／删失处理、自身最低收益及相对收益改善标准、风险不劣标准、样本支持和不确定性判据。当前尚未决定的窗口及阈值留 null；冻结协议不产生额外数据或执行权限。确认反馈再用于选型时须登记暴露，后续新确认另选合法未使用证据。不劣与改善分别判定；缺项、证据不足或不通过时保留已验证基线和未知，不能作正式采用。

## 四、何时介入，何时不介入

1. 重大泄漏、伪收益、身份或现金错误：立即定向纠正受影响动作与结论，保存原失败、版本和下游影响，必要复验后才能解除对应限制；不泛化成全线停工。
2. 连续三个**输入可比且反馈完整**的无改善周期：依 MS015 在原名额／原预算内提出一项有依据的方法假设。不得用源码检查、重复初始化、摘要计数或不同评分合同凑足三次。
3. 连续两个**已结束的自然边界**只有准备核验、未改变判断：依 MS013 降低该方向优先级、比较另一独立机制；保留当前正确性所必需的修复。
4. 未知、在途、等待外部依赖、用户暂停和没有新增快照不计失败或停滞，不按自然小时累加。首次未核完整连续证据链时计数为 null；换输入／评分／对照后不能接续原比较计数。已有完整负结果可用于下一假设，但不重新打开封存表达。 对候选承接，尚未明确承接者、未实际交接或未得到处理决定时，属于待协调动作；不能仅写“等外部结果”就反复结束巡检。等待账户期间，有独立依据且在原授权内的数学推导或诊断可继续，不虚构研究动作填满时间。

### 4.1 先提出可检验的改法，再验证是否提效（2026-10-07 补充）

上述连续计数用于升级介入，不是开展有依据的离线诊断、准备竞争解释或提出方法假设的唯一入口。重复出现的已核完整账户负反馈可以触发原准备预算内的一次有界诊断；三个账户结果不得冒充三个完整方法对照周期。未知、在途和暂停仍不计失败，不因日历或催促强行改法。

同任务、同预算对照及完整成本是判定“方法已改善”和正式采用改法的门槛，不是总控提出诊断或改法的前提。缺少对照时允许提出假设并记录未知，不能因此无限期只巡检，也不能宣称旧 loop 高效或新 loop 有效。诊断必须说明竞争解释、哪项现有证据可区分它们、下一行动会改变哪个研究判断；时间盒结束无答案则保留具体缺口并降低重复方向优先级，不扩建表格或重算未变化的有效核验。当前冻结实验继续使用原合同，在线方法变更仍遵守原试点准入与回退要求。

总控自己的阅读、维护和消息成本也纳入后续完整成本。每轮先核“哪一个判断改变、下一问为何更有价值”，再追所需原件；无变化不重复审计。送达、执行正确、提出更好问题、提效、开发收益和独立确认分别判断。

每线最多一个在线方法试点，先查原试点是否关闭；在线名额未知时不能叠加。新旧方法应处理同任务、同输入暴露和同成本口径，在原预算内事前冻结改动面、停止与回退条件；保留旧 loop。失败、无优势或证据不足按原规则保留／回退。不得追加账户／原生／付费额度，不能用改变评分器、阈值、窗口或子集自证成功。

每条介入必须带唯一 id、接收线程、触发原证据路径／哈希、明确有界行动、原授权与预算、适用自然边界、预期证据和复查条件。去重指纹取 `SHA256(目标线程 + 问题类型 + 触发证据身份/哈希 + 行动版本 + 自然边界)` 的规范 JSON；不把观察时间或每次游标放进指纹。发送前同时检查原 guidance 与介入记录，相同问题、证据和行动不重复催促。发送结果未知先按原消息身份查回执，不能直接重发。

### 4.2 历史收益与新框架之间的核对（2026-10-07 补充）

更换开发窗口、撮合模型、数据时点、训练目标或仓位映射后，旧高收益记录仍须保留明确去向。总控在下一自然边界先复用已有原件，核对旧候选、当前同口径父本和新候选：哪些差异来自必要的正确性修复，哪些来自策略取舍，哪些尚未知。无法同口径比较时，分别保留历史成绩及其限制；不得仅因窗口变化、quality=null或换框架就认定旧结果失效，也不能把旧成绩直接当成新框架合格基线。

“本轮通过”和“当前受限分支最好”不能扩称全线历史最好或整体优化。风险约束合格但收益显著缩水时，必须核对资金使用、成交规则和预测到仓位映射，并比较其他满足同一风险目标的独立机制；不能只在低收益分支内不断换模型。已有明确变化链即可在原准备预算内启动有界诊断，不等待凑满方法周期。旧规则保留作研究对照，涉及新账户的比较仍须在原授权、名额和预算内事前冻结；不得恢复旧失败、重判旧阈值、重跑未知任务或读取封存2026。

若在原时间盒内无法解释差额，记录一个具体缺口及其对下一候选选择的影响；降低无新信息的同类搜索优先级。历史核对可以改变问题选择，不能冒充同预算方法提效、因果收益归因或独立样本外通过。

## 五、介入效果和写入方式

`INTERVENTIONS.jsonl` 是原 guidance 的轻量补充，每次新增介入或取得新证据追加一条事件，用同一 id／fingerprint 关联，不新建全项目状态库。必须分别记录：

| 阶段 | 必需证据 |
| --- | --- |
| 送达 delivery | 工具实际接受／未知及回执；由总控转述时明确 provenance，原工具回执缺失留 null |
| 已采用 adopted | 原计划／冻结件明确使用该方法，含版本和自然边界 |
| 已执行 executed | 原执行回执、真实输入及总成本 |
| 证据改变 evidence_change | 新证据改变了哪个判断，引用原裁决与核验 |
| 开发收益风险 development_effect | 正确完整同口径账户、固定对照及原费用风险标准 |
| 独立样本外 independent_oos_effect | 事前完整确认协议、未暴露样本、支持／不确定性与不劣／改善结论 |

未知均留 null，不能把送达沿链自动提升。没有同任务／同预算的因果对照时，只写“前后观察关联”，不能把随后所有收益归功于提示词。MS028 的目标／评分接入也不等于方法提效。

共享写入沿现有 `.state.lock` 短锁，提交前校验 STATE revision 和受影响文件哈希，原字节先备份，临时文件写完后原子替换。冲突只重读受影响字段并重做该小范围更新，不覆盖别人的修改、不清锁抢写；独立目录内已授权工作继续。游标、每日／每周完成标记、介入回执、自动化首次实际触发均并入原 STATE 对应字段，记录时间与来源，不覆盖各研究线的 CURRENT、预算、暂停或冻结源码。
