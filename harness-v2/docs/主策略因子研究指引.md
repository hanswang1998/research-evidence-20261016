# 主策略因子研究指引

2026-09-22，候选生成初版。用于结构线与 ML 线准备下一批候选；按需加载，不要求状态查询或每轮核账重读。本指引改变候选准备方法，没有经过研究效果对照，不能据此宣称已完成 Dream RSI 复现或策略自进化。

## 1. 先确定要增加什么信息

先从完整机会池、遗漏的可执行盈利机会及同条件失败案例提出研究问题，再检索知识库。不能只围绕当前胜者修补，也不能因论文公式多就全量搬入。一项原规则消融有研究价值，但它是对既有结构的检验；换模型、标签或仓位也各有作用，均不自动等于增加因子信息。

在本线已有 PLAN.md 中补一张简短覆盖表：机制族／输入来源／已做表达和反证／尚未覆盖部分／可用数据与缺口／本批选择或延后理由。按经济机制和信息来源比较，候选数量、公式数量、模型次数不能代替覆盖情况。不规定每族必须占多少名额；若本批全是旧规则或同输入模型变体，说明为什么它们比可准备的新信息候选更值得，并保留后者的具体准备项。

## 2. 把知识真正转成候选

当前共享知识库入口为 [v5 知识库](../../聚宽回测v5/知识库/README.md)，只读使用。查询工具为 C:/Users/Administrator/Desktop/聚宽回测v5/tools/knowledge_query.py，可用 --question、--line 一进二、--mechanism 和 --format json 限定检索。查询缺少实验索引时，不据此断言从未做过；回到本线协议及报告排重。默认短检索没有命中时，可对相关台账的标题、ID 做定向检索，不默认遍读全文库。

对入选线索，读取准确原文段落并区分原公式与本项目改写。在已有 CANDIDATES.json 的候选规格或引用件中补充以下内容，不另造一套全局登记系统：

- 知识 ID、原始来源及段落；对应市场、频率、持有期与我们的差异。没有外部来源的原创提案可明确标注，并给内部证据。
- 机制假设、可证伪结果、预期作用位置：选股排序、入场、风险或执行。
- 可复现公式／程序规格：输入、单位、窗口、输出、缺失和极端值处理、最晚可见时点；原表达与项目适配分别记录。设想、可计算和已验证分开。
- 与现有特征、历史失败表达的关系；新增信息究竟来自新数据、时间顺序、相对比较还是条件关系。不同名称、多个窗口或多列数值不天然独立。
- 固定对照、筛选与完整账户验证方式、搜索总预算、所有尝试的保存位置及停止条件。只引用论文或复述摘要，不算完成因子准备。

可作为首次检索种子的方法包括 Alpha101（FC-674a33dcad24343e7b9f）、Alpha²（FC-71b33aa654b5cfe72535）、FactorEngine（RC-fa5a88170f9aeb1bcdcb）。它们提供表达方式、去重和知识转程序的借鉴，不是本项目有效因子的认证名单。论文的通用股票池、目标收益与交易方式须重新适配一进二。

## 3. 批量构造与检验

1. **先检查适用性和重复信息。** 在首板条件下，某些通用指标会接近常数；某些路径表达可由已有价格或均价还原。复用已验证的恒等式与反例。相关性诊断、同条件比较或训练期残差检验用于检查冗余，不能把“低相关”单独当成预测增益。
2. **明确数据够不够。** 优先准备已有日线、前一日分钟、合法开盘信息和历史市场状态可支持的表达。板块／行业比较需要当时可知的成员映射；逐笔订单流、撤单、委托簿恢复需要对应数据。分钟代理按其实际含义命名。缺数据保留具体依赖，不杜撰字段、不把事后归属提前使用。
3. **一次计算同口径因子面板。** 同一机会池、同一决策时钟、同一成熟标签和时序切分；共享已验收输入与算子，各候选输出可区分。按现行计算指引使用 Polars＋Parquet。计算一批表达不等于派发多条经济账户，仍遵循现有执行接口。
4. **先设计有限搜索，再看结果。** 可以事前声明少量窗口、算子及训练期参数搜索，冻结搜索空间和总预算，并保留全部尝试；超出原规格的事后改写另立版本。预处理、阈值、参数和特征筛选仅用指定开发／训练资料，标签要在相应训练时点成熟。已经用于选题或调参的历史不能重新包装成独立样本外。
5. **固定对照检查增量。** 新因子对照原特征；能合理解释时另做去除该族、保持输入只换模型的比较，区分信息、模型和账户规则的贡献。考察跨时间稳定性、冗余、条件差异、未知覆盖及实际选择变化；预测相关性和排序指标只是诊断。只适用于某种已知市场条件的表达可以单独声明并检验，不能强求所有因子全市场线性单调。
6. **回到可执行净收益。** 信息检验后按原协议决定完整账户验证，沿用费用、成交、现金、库存和原目标。不额外给已有完整账户候选强加随意短窗收益门，也不以论文成绩、单因子相关性或代理标签代替自身账户。完整账户开发结果、原生核验、独立验证与采用仍分别裁定。

## 4. 反思应改变候选生成

原有三问反思同时回答：本批增加了哪些可识别信息；哪些只是已有规则或信息的重述；知识来源改变了哪个具体表达；为何下一批转向或继续这个机制。复用有效证据，不按轮重做覆盖表和检查。

当前可执行调度器主要比较修复、延伸、探索的次序与深度。它不会自动生成因子库，历史调度分数也不能证明候选质量提高。若后续修改候选生成或评分方法，在新批次明确冻结版本及评测口径，保留旧版。观察真实有效结论、信息增量和总成本后才判断改善；不在当前冻结批次中追改评分或政策。

交付首先是可计算的候选规格、覆盖与反证表，以及清楚的就绪缺口。由各线原交接引用即可，不要求额外长篇自评或重复核验。
