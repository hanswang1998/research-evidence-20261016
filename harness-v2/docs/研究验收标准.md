# 一进二研究验收标准

## 新未冻结评价规则（2026-10-13）

版本 `evaluation-20261013-v1`，依据用户本次“把各条线的评价规则改好，优先解决这三个问题，不要只是增加指标；已有冻结实验不动，也不要因此恢复暂停的研究”的授权。它替换新开发中的逐次收益／回撤双优、通用年化增量5个百分点及删任一年必须领先的判胜要求；不放宽20%风险上限、正确性、强对照或独立确认要求。各线更具体的预算、停止和执行授权仍按原件；新规则不解封2026、不换父本、不启动研究。

### 先分资格，再判断改进是否足以改变决定

1. **资格**：正确且可比的完整账户、买前时点、真实可成交性和关键未知按原要求核验。故障、数据缺口、诊断结果都不能取得经济胜负结论；必要检查不因结果看起来差而跳过。
2. **开发比较**：先看原始日终最大回撤≤20%及自身费后盈利，再看同口径费后几何年化增量（百分点），以净利润差核账；回撤无需低于父本。净利润、累计收益和同窗年化是同一终点的表达，不重复计为多份支持。直接父本、已审阅范围内最强风险合格对照、同框架高收益参考沿原PLAN事前固定，角色可重合；仅胜过弱父本叫局部改善，不能叫全线胜出。
3. **晋级取舍**：观察到正差不自动换父本或送最终确认。原PLAN验收段在看本轮结果前说明“什么程度的差异值得改变下一决定”，根据已有费用／容量敏感性、数值精度或适用的差异不确定性证据给出实质增益依据，并固定一种能检验当前主要脆弱性的对照或压力情景及拒绝条件。可复用已有有效证据；不要求每轮重算全部诊断。不凭空统一改成另一个百分数，也不把事后挑出的情景称为事前验证。
4. **证据不足的处置**：无法给出有依据的实质增益判据，或关键敏感性仍未知时，保留“观察改善、晋级证据不足”，维持原父本；可在原授权和预算内继续诊断或准备独立候选。细小差异、数值并列、合理扰动下方向不稳，不按严格大于零自动选优，也不判机制无效。低收益但风险／执行明显更好的候选可留作取舍候选，明确收益代价，不称经济达标。

### 重复开发与独立确认

- 2020—2025反复参与选题或选型时持续标开发。原PLAN沿用已有候选池／尝试记录，注明这次改变了什么、哪些依据来自已见结果、有限搜索预算与停止条件；报告引用全部尝试，不只保留赢家。实验编号、修复次数和高度相关变体数不当作独立检验数，不另建总台账。
- 年化领先5个百分点不再是通用判胜／送审门槛。删年、分年、随机排序及区块扰动只按各自能回答的问题使用；删年复利不是重跑删年账户，少量随机种子不是显著性证明，普通bootstrap区间不能冒充校正整个选型过程后的置信区间。删年失败触发收益来源检查，不自动否定全部表达；删年通过不解除重复选优偏差。
- 若要主张统计可靠性，必须在看结果前明确检验对象、依赖／重叠处理、搜索范围及方法适用条件。当前证据不支持就保留待确认，不靠叠加多个相关门槛制造确信，也不强制为每个失败候选新增统计计算。
- 独立确认前固定候选、强对照、窗口／终点、最低经济效果、风险与支持／不确定性要求；只用未参与这一候选及规则选择且本线已获授权的数据。已暴露数据不能重新封存后再称独立；其他线的2026授权不传播。确认失败保留，考后修改成为新开发，不能继续使用同份考卷反复“确认”。正式采用、换父本仍按原用户授权。

### 开发期滚动验证（2026-10-16）

v2 可选做法：只在批次边界冻结 `walkforward_contract` 后生效，先在一条线上试用；在途冻结件不变。它落实上文第 3 条“晋级取舍”中的实质增益依据，不另设加权评分。各线目标是否改为以此为准，由用户另行决定。

1. **合同在看结果前冻结。** 默认：完整可见窗口 2020-01-01—2022-12-31；验证折 2023、2024、2025 各一年；至少 2 折年化胜过父本、各折平均年化差不小于 0、每折原始日终最大回撤不超过 20%；每窗口至少 60 个交易日且不低于工作日数的 85%；候选与父本交易日历必须完全一致；250 日年化。各折不得与可见窗口或彼此重叠，以免通过相减还原被遮蔽的数字；任何一折不得触及 2026。各线可在事前收紧，不能放宽。
2. **由控制器在核账之后计算。** 输入为候选与父本同口径完整账户的逐日权益。Agent 可读的版本只含可见窗口的完整数字，以及每折的胜负、回撤是否合格和差值区间（<-10、-10—-2、-2—+2、+2—+10、>+10 个百分点）；完整数字写入 Agent 不读取的位置。这是工作约定，不是技术隔离，须如实记录是否被打开。
3. **只在全窗口上胜出不是改进。** 冻结了滚动验证合同的批次中，`observe` 只在账户评分改善且滚动验证 `pass` 时接受 `valid_improvement`。全窗口改善而验证失败，记“观察改善、晋级证据不足”，按 `valid_negative` 登记，保留原父本。
4. **仍属开发证据。** 2023—2025 已被反复查看，现有父本在其上的通过只是弱证据；对新候选，遮蔽能减缓继续过拟合，但不等于未见样本。独立确认与正式采用按下文“重复开发与独立确认”执行。

**本地与原生偏差抽检（建议）。** H543 同源码、同窗口：本地年化 306.38%、回撤 15.56%；聚宽原生年化 293.90%、回撤 17.67%。建议在原授权与额度内定期抽本地候选做原生对照，记录年化与回撤差；累计偏差用于解释本地结论的不确定性，不用于事后修正单个结果，也不作为每轮必过的门槛。

**容量与涨停成交（建议）。** 现行 5% 容量以当日全天成交量计算，下单时不可知；涨停买入只检查价格条件，没有排队模型。建议在需要晋级的候选上补一个用决策前可知量（如前 N 日均量）计算容量的敏感性结果，并对涨停买入成交做排队敏感性检查；未做时在结论中明示为未知风险。

### 执行失败与经济反证

| 实际证据 | 应有结论与下一决定 |
| --- | --- |
| 工具／参数／绑定／实现失败，或账户未通过必要核验 | 实现故障或证据不足；经济结论未知，不计经济失败或连续无增益，不否定机制 |
| 原计划是数学、信息或机制诊断且已回答问题 | 只给该层结论；能改变下一决定即可，不强制补账户凑数 |
| 正确完整账户不盈利、超风险或未改善 | 保留对应有效经济反证，按冻结表达及已测范围判断；不能扩大到整个机制族 |
| 数值改善但幅度／稳定性／强对照证据不足 | 观察改善、晋级证据不足；保留原父本，可暂存取舍候选 |
| 满足事前实质增益及关键脆弱性判据，经相应核验 | 开发证据支持，进入下一合法验证或报告节点；不是独立确认或正式采用 |

工程预检复用已验收接口，只对本轮真实变化检查参数、输出字段、来源绑定／持仓顺序等可能使下一决定无效的路径；可用最小合成夹具或已有fixture验证，不读取新增行情、不暗跑经济账户。共用故障先在共用接口关闭，未通过的依赖候选暂存，不把同一故障轮流分摊到新经济表达。

失败花费、执行尝试及已消费授权如实保留；“不计经济失败”不等于返还额度或重置修复预算。达到真实用户／冻结预算时结束受影响执行；机械关闭不等于经济否定。本次不重开旧关闭件，也不覆盖旧裁决。连续无增益只能触发按证据反思、转向或暂存，关闭整个机制需要支持该范围的反证及未测范围说明，不能仅按两批计数自动关闭。

### 不增加一套评分或记录链

只在原PLAN／SPEC的验收段绑定本版本、固定对照和上述决定条件；原RESULT／REPORT给出一个主结论、证据与下一决定。已有字段可表达就复用，严格schema不能添加字段时放进原REPORT并引用，不另设评分表、逐轮审批或绩效台账。

现有`review-account`继续计算真实账户数值，`quality`、`return_improved`及`observe.valid_improvement`只表达其原开发数学含义，不编码本节的实质增益、选择偏差或父本晋级决定。按原接口登记真实数值与状态，在原报告另说明是否足以改变决定；禁止伪改quality、把正差改成经济负值或绕过observe。下一批生成裁决脚本时按本版本生成结论分支，不复制旧“双优／5个百分点／删年全胜”的自动赢家逻辑；若现有接口仅能给原分，保留原分并由原裁决说明证据层级，不能宣称已自动执行新晋级规则。

归档与范围见[本次变更记录](../analysis/research_governance_20261008/evaluation_rules_20261013/CHANGE.md)。在途冻结文件及其原哈希不修改；历史只按其原版判定，必要时从本次原字节备份取回对应规则用于追溯，不改旧预期哈希或倒判。暂停／已结束研究只收到规则，获得真实恢复授权后才在下一合法边界应用。

本页是[当前研究目标](当前研究目标.md)的账户验收口径，依据用户确认的[MS028](../analysis/research_method_supervision_20260922/MS028_风险约束下收益优先与评分接入.md)。目标变更只用于新未冻结实验；旧合同与裁决按文末历史边界保留。运行状态由各线权威入口查询，不在本页复制。

## 账户评价顺序

1. **正确且可比**：同初始资金、同窗口／日历、费用和成交规则；候选和事前固定对照都经过完整账户核验。买前信息可观测，完整机会池保留未选、未成交与未知，持仓／现金／订单／费用逐项闭合。
2. **风险约束**：最大回撤由原始日终净值及初始本金峰值计算，≤20%合格，超限不进入达标完整策略集。不能事后改变杠杆／预算把结果缩到上限。
3. **收益比较与晋级分开**：合格账户统一报告同窗口费后几何年化、原始最大回撤、Calmar及对照年化差（百分点），净利润／累计收益留作核账；是否值得晋级按上文事前实质增益与关键脆弱性判据决定。已有收益集中、日期／交易支持及成本敏感性用于解释这个决定，不增加加权总分。胜率、预测分数或较小回撤不能替代赚钱比较。
4. **独立确认**：开发／选型胜出还需按事前确认协议检验。具体确认最低收益、增量要求、支持／不确定性及窗口未齐，不能判确认通过。开发评分器不授予确认或采用。

默认开发区间2020-01-01至2025-12-31，实际交易日历及日数由原数据绑定。更短的训练／选型窗口事前指定并只在同窗比较。2026封存；跨年标签保持未知。已用于研究方向或候选选择的日期仍为已使用数据。

## 固定比较与数值口径

10万元本金、空仓开始、无外部现金流；固定原费用（卖出税0.001、买卖佣金各0.0003、最低佣金5元、固定滑点0.01元）及原交易规则。若另有已授权且事前固定的成本压力情景，主情景和压力情景分开，同一情景候选与对照相同。费用改变不能与信号改善混同。

`net_profit=期末权益-初始本金`，`net_return=net_profit/初始本金`，输入比例而非百分数。**各线统一以费后几何年化收益率、原始日终最大回撤和Calmar展示与评价迭代；主要收益增量为较事前固定对照的年化差（百分点）。** 风险合格后仍以年化收益改善为主，不以Calmar单项上升代替赚钱能力；实质增益及独立确认要求不变。同本金、同窗口时年化与净利润排序等价，净利润和累计收益率保留为核账底稿。本金相同不能消除窗口、费用、撮合、容量或对照差异；这些条件不一致时分组，不跨组排名、不线性缩放本金或由年化倒推利润。平台四舍五入回撤不替代原始日终净值回撤。缺日不填零，精度裁决保留原Decimal／币值证据。

2026-10-14 统一公式及输出：`annual_return_250=(期末权益/初始本金)^(250/N)-1`，N为完整窗口实际交易日数，含空仓日；缺日不能补零或缩短N。`max_drawdown_raw`沿用含初始本金峰值的原始日终最大回撤，`calmar_250=annual_return_250/max_drawdown_raw`；零回撤、负期末权益或缺少计算依据时相应值为未知，不填无穷。比例存小数，年化／回撤展示%，年化差展示百分点，Calmar无单位；原平台年化单独注明公式，不混用250／252日或算术年化。

下一未冻结批次的原 RESULT／REPORT 共同提供这三项指标及直接父本／固定强对照的同口径指标、年化差（百分点），并引用实际起止日、N、本金、终值／净利润、费用／撮合／容量合同。已有等价字段复用，严格schema放原REPORT，不另建台账；缺字段标未知。只有数学正差仍不能自动晋级；历史原指标与原裁决保留，可另做标明公式的统一展示，不改冻结件。数学／信息／工程阶段仍按本阶段判据，不为了统一展示强跑账户。

原指定compact源码与严格涨停修正版保留来源与缺陷说明；新评分主对照为事前固定、正确且与候选同窗同撮合的实际父本／严格修正版。旧原生六年数值不能替代新的2020—2025本地参照，也不能把带未解释现金事件的旧账户声明为已正确核验。固定父本对照和原指定参照的关系在原PLAN写清，不追溯改写历史基线。

本地分钟初筛使用候选自己的连续现金账户及同撮合对照；原生Tick需原授权并另核身份、订单生命周期、费用、持仓、现金。跨频率差异未校准时只能作诊断，不能直接比较其数值并宣布正式胜出或永久否定另一撮合假说。原生回测本身也不等于独立样本。

## 程序入口与结论

新评分使用[MS028适配及命令](../analysis/research_method_supervision_20260922/MS028_风险约束下收益优先与评分接入.md)；结构／ML在下一调度批次冻结v2合同，市场／专题只运行同一review-account入口。账户缺失、不一致或核验未完时不评分；信息实验仍按原信息判据，不能编出账户分。

| 结论 | 可说明的事 |
| --- | --- |
| 正确性修复 | 修复对应错误；不能因修复后历史收益下降而恢复错误。 |
| 开发／选型收益改善 | 风险合格、自身盈利、相对固定对照净利润增加是观察事实；是否有足够证据晋级按上文判断，仍需独立确认。 |
| 风险修复取舍 | 从不合格风险降至上限内且自身盈利，但收益未更高；明确少赚多少。 |
| 不达标或未知 | 超限、负利润、零参与、同风险约束下未超过对照各自保留；证据缺失不当作经济反证。 |
| 独立确认 | 仅按事前完整协议及足够新证据判定；不能由开发分数推出。正式采用另需授权。 |
