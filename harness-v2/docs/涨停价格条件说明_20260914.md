# 涨停价格条件说明

此前报告标题中的“修正涨停价比较”，精确含义是：把扫描昨日连板及扫描全市场候选的六处价格判断，从容许0.01元或0.02元差额的近似条件，改成适用证券按整数分精确比较。原未知价格或未识别证券分支仍按原回退规则处理，并非全项目的涨停比较全部修改。

例如已捕获的2024-06-04候选601933，其一根扫描收盘为2.63元、该根涨停价为2.64元。原候选扫描的0.02元容差把这一根算进近似涨停；整数分比较263与264不相等，严格涨停条件不成立，进而改变连板/首板分类与候选池。调用中原始数组没有单独的行时间戳，不为这根价格猜具体交易日期。

这不是调整下单报价，也不只是浮点数误差修复。它改变了选股条件，可能影响弱市、强市和谨慎三种模式。准确名称应为“近似涨停条件改成严格涨停条件”。原规则是否属于程序错误，取决于策略本来要表达严格封板还是接近涨停；收益高低不能决定这个语义。

该研究近期收益52.50%、回撤12.52%，相比当前现金父本42.17%/14.31%更好；实际改善来自少买一个弱市亏损周期，30个谨慎周期未变。全窗终值1886.3864倍、回撤29.85%，弱于父本1974.8373倍/29.77%，因此未按研究门槛采用。不能由此说“真正的错误不修更赚钱”，也不能把近期收益提升算作谨慎排序已经改善。
