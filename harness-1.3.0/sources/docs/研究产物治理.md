## 研究 AI 每次写文件的要求

这些要求用于已授权工作的新增或实际修改链条。格式和读取接口的变更在正常实现边界完成兼容验证；本规范不自动恢复暂停研究。

1. **先查复用，再决定落盘。** 只查本次任务和已知引用。来源、窗口、字段、买前可见时点、训练截止日、标签成熟规则及转换版本均一致的已验收数据直接引用；不能按实验编号复制全量，也不能混用不同截止日的数据。已有有效哈希及核验可复用，不为此每轮扫描全库或重算大文件哈希。
2. **大明细一份，摘要单独留。** 新增大表使用 Parquet，默认 Zstd 级别 3，遵循各线计算指引，保存有类型的实际列；不要把完整 JSON 塞进单个 payload 字符串冒充列式改造。保持精度、身份、时序和未知语义，不同时导出同内容的完整 JSON、CSV、Parquet。必要兼容导出须在原计划写清调用方、范围与保留理由；不覆盖旧冻结原件。
3. **交接写结论和引用，不复制历史。** 保留当前必需状态、结论、未决项和不可变证据路径／哈希；不递归嵌套旧交接、账户明细或逐行结果。可重建索引按短锁与版本校验更新，不能以“只留最新版”覆盖冻结输入、原始记录和正式裁决。
4. **按读取需要分区，不默认每天一文件。** 优先使用批次、月度或其他经消费者验证的合理分区，以行内身份定位；不默认每条记录、案例或股票日一个小文件。共享不可变块、增量记录和必要完整检查点应替代反复复制大对象；保留精确恢复及中断恢复能力，旧消费者未适配前不裁剪旧历史。
5. **公共输入和环境不随实验复制。** 共享键绑定内容、来源、转换、依赖和工具链版本，隔离可变输出并控制并发写入。运行库须核对内容与版本兼容，不能按同名同大小推定重复；被共享的不可变版本不得原地升级。实验仍保留自己的源码／配置身份及必要模型、预测、账户和独立核验证据。
6. **日志保留新信息，公共内容引用一次。** 已核实的重复公共输入或长前缀可按内容哈希共用；记录本次调用身份、差异、时序及返回结果。同类重复错误保留次数、首末位置与必要原文上下文，新错误保留充分证据。部分日志约八成公共内容重复的观察，不等于所有日志八成都能删；唯一订单、现金、失败和未知不能被摘要或去重替代。
7. **由生成器预估与累计，在已有回执记一次。** 原计划写预计文件数／逻辑字节量级、主要大件、分区及复用位置；写入器累计本次实际新建文件数、逻辑字节和覆盖重写量，并在原完成回执记生成器版本、复用身份及必要大件理由。缺项写未知，不补扫全库，不另建每日治理报告、逐文件收据、重复总台账或每次写入快照。
8. **临时文件有归属，证据保留有边界。** 明确可丢弃、可重建、不被引用且无活跃依赖的自有临时产物可在原流程收尾清理；先核最终路径、目录归属和重解析点。大文件确有研究用途即可生成，在原计划解释必要性，不以统一大小上限妨碍完整证据。

原计划可写：`预计产物：文件约 N 个／逻辑字节约 B；主要生成器及分区；复用位置；必要大件理由。`

原完成回执可写：`实际产物：生成器版本 V；新增 N 个／逻辑字节 B；覆盖重写 W；复用版本及引用；必要大件理由；可重建临时位置。` 未测字段写未知，两行均不另建文件。

## 接入与验收

- 共用规则以本页为准，各线入口只放简短引用；只适配本次真正调用的写入链条，不为治理重跑历史或停止无关研究。
- **计划、实际启用、存量释放分开。** 修改规范／提出方案是计划；代码接入且真实产物已按新合同生成，才叫实际启用；压缩、去重或清理后的实测空间变化，才是存量治理效果。代码存在或逻辑大小下降不等于物理空间已释放。
- 新写入器在原计划／完成回执中保留上述合同的验收结果和生成器版本；在同等研究范围下比较实际文件数、逻辑字节及重复输出。只复用输入、实现和判据未变的有效核验，有新差异再定向补查；失败回退旧合同。
- 当前已核实的接入例子包括 [ML compactcapital619.py](../analysis/yjj_ml_research_20260921/compactcapital619.py) 与 [ZB compact_state.py](../analysis/zb_takeover_20260929/adjustment_20261005/thirtyfourth_local_pool_20261008/compact_state.py)，后者由同目录的 `controller.py`、`freeze_pool.py` 等在新边界调用。实际版本、产物与核验以各自原回执为准，本页不复制动态状态；这些接入不代表其余旧生成器或旧存量已完成治理。
- ZB 旧 `adjustment_20261005/common.py::state_commit` 受既有冻结哈希约束，不能因新边界已接入就热改旧合同或删除旧历史。剩余存量按下节有界处理；新合同不自动授权其他研究动作。
- 共享文档、索引及当前引用的实际修改使用短独占锁和读取版本／SHA 比较；发生冲突只重读受影响文件／字段后重做。大文件哈希、压缩或复制在锁外准备，提交前重核身份与版本，锁内只做必要替换／引用更新，不长时间占锁。

## 存量治理与空间核算

1. **有限清单是执行记录，不是重复审批门槛。** 在已有治理回执记录绝对路径、用途、处理方式、来源／重建条件、引用与活跃性、预期保留路径及回退方式；复用已有盘点，不反复全库扫描。首次必要盘点仅取元数据，跳过 `.git` 和重解析点，记录并发写入下的观察时段。
2. **本次授权内直接实施已核实的保全治理。** 明确范围内可执行保持证据字节和读取路径的 NTFS 透明压缩；对已核实同字节、同卷且不可变的副本，可在保留原路径与回退能力、验证无原地写入风险后共享；可清理已证明可重建、无活跃依赖的自有缓存／临时产物。无需再次询问同一授权，不能用宽泛通配符扩大范围。
3. **唯一或不明证据先留。** 活跃冻结件不得原地裁剪、重编码或更换其写入合同；唯一账户／行情／失败记录以及引用、活跃性、重建条件不明的文件不得直接删除。先补最小用途证据；只有实质超出当前授权或会造成不可恢复丢失时，才就具体动作请求确认。旧证据的归档按上表验证原字节、路径映射及恢复，不以只留摘要替代原件。
4. **提交前后核验。** 长操作不持共享状态锁；准备完成后检查来源未变、保留副本可读和哈希一致，再做短锁／版本校验下的必要替换。实际复制、替换及回退接口先用自有临时件验证；替换接口可能继承旧压缩属性，不能只核内容一致。处理后从原读取入口复核原字节及最终分配量，临时副本的压缩率不算已释放空间；兼容核验失败则保留原件，明确记录未执行。异常只在完整备份可恢复时回退，删除备份已开始后不得用残缺备份覆盖已核验副本；不可变硬链接对象不得被任一调用方原地写入。Windows 删除／移动在一个 shell 内完成，逐个确认最终路径位于明确 workspace 内，不跟随重解析点递归操作，不将枚举结果拼接成另一种 shell 命令。
5. **逻辑长度不等于可释放空间。** 分别记录逻辑字节、必要范围的分配量、唯一文件身份和硬链接数；删除一个硬链接名称未必释放数据，NTFS 压缩也可在保留文件及路径时释放空间。已压缩文件不能把逻辑长度当作待释放量；相同名称／大小的运行库不能直接认定为同内容。 精确分配量读取文件系统 AllocationSize 或等价接口，并按卷与文件身份去重；GetCompressedFileSizeW 对未压缩文件可能仅返回逻辑长度，不能单独作为全目录精确占盘值。跨盘映射、文件系统管理开销和并发观察时段另外说明。
6. **以实测完成验收。** 在原治理回执记录处理前后 C 盘可用空间、测量时段、受处理对象分配量及恢复核验；同时说明并发写入等干扰，磁盘净变化不冒充完全由本操作造成的释放。未执行释放操作时实际释放为 0，执行后未测为未知；计划量、逻辑节省、物理变化分别列明，不再为计量建立额外逐文件审计产物。
